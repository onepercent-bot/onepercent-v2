## 2026-11-02
- **«Предплечья» расширены** только упражнениями, где предплечья реально работают (молотковые сгибания, Зоттман, прогулка фермера с приседом); висы, становая и шраги — нет — поле `extra: ['forearms']` в данных. В Vital всего ~9 упражнений с предплечьями как основной мышцей. Эти упражнения остаются и в своих основных разделах.
- **Вкладки «Зал / Дом / Без инвентаря»** вместо коллекций Vital. Поле equipment у Vital неточное («body weight» у подтягиваний, брусьев, скамьи), поэтому в данные добавлено `needs` — снаряды из описания Vital + поправки по кадру видео (~40 упражнений). Дом — без тренажёров, блоков, штанг, стоек, турника, скамьи, тумбы; гантели, гири, резинки, мячи — можно. Без инвентаря — только свой вес и ничего не нужно. В домашней коллекции Vital «скамья/тумба» = мебель.
- **Экран групп мышц** — сетка 2 колонки, иконки — картинки владельца (сгенерированы в ChatGPT), голубой приведён к акценту Главной #8cc4fb (светотень сохранена): тёмная фигура, группа подсвечена; `src/assets/groups/*.webp`. Иконки, нарисованные кодом (SVG), отклонены.
- **Подпись инвентаря** берётся из `needs`, если Vital пишет «свой вес», а нужен снаряд.
- **Кадры Vital без заливок и размытия.** Карточка — видео целиком в своих пропорциях (высокое — не выше 62% экрана). Плитка — ровный квадрат: неквадратный кадр обрезан по длинной стороне вокруг человека (`video.pos`, подобрано автоматически по кадру + ручные поправки; проверено по всем 335 неквадратным кадрам). Заливки полей и растворение краёв отклонены владельцем. Срезается тонкая тёмная рамка исходника (1%).
- **Персонаж строго по полу.** Мужчине — только мужские манекены; домашняя коллекция (брюнетка) — только женщинам.
- **«Руки» делятся на Бицепс / Трицепс / Предплечья** (по `target`); предплечья оставлены, чтобы не терять упражнения.
- **Список упражнений — плитки по 2 в ряд**, одной высоты (название всегда 2 строки). Кадр не обрезаем: часть видео не квадратные, обрезка срезала головы/ноги/тренажёры. В данные добавлены `video.ar` и `video.bg`, рамка исходника срезается на 1%.
