## Архитектура

- Навигация — состояние в `src/App.tsx`: `welcome | onboarding | summit | app`, внутри `app` вкладки `home | progress | exercises | profile`.
- Нижняя навигация: Главная / Упражнения / Прогресс / Профиль. Дизайн-система — `.claude/skills/onepercent-v2-ui`.
- Прогресс: история тренировок в `localStorage` (`onepercent:workouts:v1`, `saveWorkout()` + событие для автообновления). Тренировки записываются из «Тренировки дня» (`src/screens/Workout.tsx`). Методика: оценочный 1ПМ по Эпли (≤ 12 повторений), без веса — повторения; сравнение только одного и того же упражнения; окно 7/30 дней против предыдущего такого же; группа и общий рост — медиана. Рекорды — по 1ПМ, отдельно для каждого упражнения категории. «Что улучшить» — правила по посчитанным цифрам; AI не подключён.
- Упражнения: группы мышц сеткой 2 колонки (Кардио — широкая снизу), иконки `src/assets/groups/*.webp` через `src/components/MuscleIcon.tsx` →
  вкладки Зал / Дом / Без инвентаря → плитки по 2 в ряд → карточка (видео Bunny, мышцы, инвентарь, уровень, техника).
  «Руки» сначала делятся на Бицепс / Трицепс / Предплечья (в предплечьях — ещё упражнения с полем `extra`).
  Персонаж строго по полу: мужчинам — мужские манекены, женщинам — блондинка, девушка-манекен и брюнетка (домашняя коллекция).
  Зал / Дом / Без инвентаря — одна функция `placesOf` в `src/data/exercises.ts`: equipment Vital + `needs`
  (снаряды из описания Vital и поправки по кадру видео); одно упражнение может быть в нескольких вкладках.
  Кадры Vital разной формы: в карточке — целиком (`video.ar`), в плитке — квадрат с обрезкой вокруг человека (`video.pos`).
  Карточка: роль (базовое/изолирующее/растяжка/кардио, поле `kind`), 2 мышцы (основная + помогающая), техника — 3 коротких шага.
  Правила состава тренировки — `src/data/plan.ts` (число упражнений по времени и уровню, доля базовых). Все 979 упражнений сверены с видео (2026-11-04).
  Данные: `vital-exercises.json` + Bunny API → зашифрованные `public/data/ex.gz.bin` / `ex.bin`;
  приложение скачивает и расшифровывает их при открытии раздела (`loadExercises`). Названия и техника — на русском.
- Анкета: тип `Profile` и функции в `src/onboarding.ts`; хранится в `localStorage`
  (`onepercent:profile:v2`, флаг `onepercent:onboarded:v2`). Анкету читают Профиль и персонаж.
- Профиль — «кто я и как меня тренировать», без повторов Главной и «Прогресса»: шапка (имя и аватар из Telegram, цель · уровень),
  «Тело» (вес, цель, рост, возраст, путь к целевому весу, «Обновить вес» → барабан), «Моя программа» (ответы анкеты; рабочие веса правятся барабаном),
  «Настройки» (единицы, «Мои данные» — скачать JSON). История веса — `localStorage` `onepercent:weight:v1`, новый вес пишется и в анкету.
  Осталось: правка остальных полей программы в шторках, замеры и фото (после бэкенда).
- Telegram WebApp изолирован в `src/telegram.ts` (в т. ч. имя и аватар пользователя — `telegramUser()`, свои копии не храним).
- Дизайн-токены — `src/styles/tokens.css`; стили по экранам в `src/styles/`.
- Персонаж по полу из анкеты (`src/data/character.ts`): мужской / женский, на Главной и в «Прогрессе»; фон — тёмный зал (вшит в картинку).
- Анкета: цель — одна или несколько (`goals`), главная — первая (`goal`), программа строится по главной.
- «Тренировка дня»: нажатие на упражнение открывает `ExerciseCard` (из `Exercises.tsx`); экран подхода: видео целиком (≤ 26 % высоты), кнопка «Техника» у названия, подсказка строкой, таймер отдыха полоской; всё в один экран.
- Экран упражнения (`ExerciseCard`): название в строке с «назад»; видео целиком (≤ 42 % высоты, при раскрытом блоке — 17 %) → параметры тренировки из программы → сворачиваемые «Техника» и «Мышцы» → «В прошлый раз». Техника переписана понятнее для 10 упражнений (пилот), остальные — в очереди.

## Данные Vital Animations (куплено)

- Хранятся у владельца на Mac (`1600VitalAnimations`), в репозиторий не кладутся.
- Все 7 JSON (1231 упражнение) сведены в один файл и лежат в приватном артефакте владельца: https://claude.ai/artifact/1S5AMVGU6tVYQgqXRGjCgF (файл `vital-exercises.json`, читать через Artifact read с `path`).
- Структура: коллекции → папка видео `NNNN.mp4` + JSON. Видео: белый фон, 3D-манекен.
- Поля JSON: `id, name, bodyPart, target, secondaryMuscles, equipment, instructions, description, difficulty, category` (англ.).
- `id` уникальны во всех коллекциях → видео связывается по `id`.
- Получено 7 JSON, 1231 упражнение: зал ~830 (100gym, 200, 100, 100female, 200female, 130male) + 399 дома без инвентаря (400home).
- Не получены: Yoga, Home/Wall Pilates, Face, Office (~370) — позже.
- ~60 упражнений повторяются в мужской и женской коллекциях (вероятно, разные манекены).
- Названия мышц непоследовательны (~30 основных, ~40 вспомогательных) — нужен словарь в наши ~15 зон.

## Очередь модулей

1. **Упражнения** — экраны готовы (Зал / Дом / Без инвентаря). Осталось: связь с Home (тап по мышце), позже — перевести репозиторий в приватный.
2. **Тренировочный процесс** — первая версия: план на 4 недели по правилам, «Тренировка дня», запись подходов → `saveWorkout()`. Дальше: AI поверх плана (поставщик — решение владельца), Главная по живому плану (неделя, последняя тренировка).
3. Muscle map (гибрид: купленная 3D-модель + маски мышц) — модель не выбрана.
4. История тренировок, прогрессия нагрузки (хранилище `workouts.ts` и расчёт «Прогресса» уже есть).
5. Бэкенд и аккаунты (перенос анкеты с устройства на сервер).
6. Видео — Bunny Stream: загружено 988 видео (все коллекции; дом — частично, ~230 не хватает). CDN `vz-fd335db2-2ed.b-cdn.net`, доступ по Referer домена мини-аппа.
7. AI-логика, питание, аналитика, профиль.
8. Выпуск в App Store / Google Play (Capacitor).
