# One% v2

Telegram Mini App для фитнеса (премиальный AI-тренер). Работаем только в этом репозитории.
Цель — большой международный продукт; позже выпуск в App Store / Google Play.

- Старый глобальный skill `onepercent-ui` (от onepercent-app) НЕ применять; репозиторий onepercent-app не читать.
- UI-правила проекта — `.claude/skills/onepercent-v2-ui/SKILL.md` (цвета, шрифты, компоненты, персонаж, навигация). Читать перед любой правкой интерфейса.

## Память проекта — читать в начале каждого чата

- `docs/PROJECT.md` — что готово, архитектура, очередь модулей.
- `docs/DECISIONS.md` — журнал решений с датами.

После каждой принятой задачи обновлять оба файла в том же коммите.

## Правила работы

- Делать ТОЛЬКО то, что попросили. Без «улучшений заодно», без рефакторинга рабочих частей.
- Не менять соседние экраны и дизайн без запроса; не удалять функциональность; не заменять assets без разрешения.
- Commit / push / deploy — только после явного разрешения владельца.
- После визуальных изменений сначала показать результат (скриншот), потом коммит.
- Внешние API/сервисы не подключать самостоятельно: сначала выбор поставщика (качество, покрытие, цена, лимиты, лицензия, хранение данных, медиа, документация).
- Отвечать владельцу коротко и по-русски, без пересказа процесса.
- Текущий код — source of truth. Не создавать дубли существующих компонентов.

## Зафиксировано — не трогать без отдельной команды

- Welcome, Home (hero, персонаж по полу — решение владельца 2026-11-03, карточки, нижняя навигация, композиция).
- Анкета — ровно 6 шагов; `NumericWheelPicker` для числовых полей (не возвращать системную клавиатуру).
- Summit (экран с горой после анкеты) — не шаг №7; анимация и тайминги зафиксированы.
- Flow: Welcome → анкета 1–6 → Summit → Home; прошедший анкету сразу попадает на Home.
- Дизайн-язык берётся из Home (`src/styles/tokens.css`, `.card`, `.cta`); новую палитру и neon не вводить.

## Данные

- Ответы анкеты (`src/onboarding.ts`, тип `Profile`) — реальные данные для будущего AI-тренера, не mock.
- Данные Vital Animations (JSON и видео) — платная лицензия. Исходные файлы Vital в репозиторий НЕ коммитить.
  Исключение (решение владельца 2026-11-01): сборка упражнений для приложения лежит зашифрованной в `public/data/` — до перевода репозитория в приватный.
