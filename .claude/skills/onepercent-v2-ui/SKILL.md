# One% v2 — дизайн-система

Источник правды — код: `src/styles/tokens.css`, `.card` / `.cta` / `.icon-disc` / `.nav` в `src/styles/base.css`,
переключатель `.ex__seg` в `src/styles/exercises.css`. Новую палитру, neon, новые шрифты не вводить.
Перед новым экраном — взять готовый класс, а не рисовать свой.

## Цвета (CSS-переменные, `tokens.css`)

| `--bg` | `#010509` | фон приложения, нижней навигации |

| `--accent` | `#8cc4fb` | акцент: иконки, шевроны, цифры роста, линии графика, подсветка мышц |

| `--nav-active` | `#8ad8fb` | активный пункт навигации |

| `--border` | `rgba(130,175,220,.13)` | рамка карточек |

| `--glow` | `rgba(90,150,220,.22)` | мягкое свечение (CTA, студия видео) |

| `--ease-out` | `cubic-bezier(.23,1,.32,1)` | все анимации |

Дополнительные оттенки из Главной (использовать только их):
- Кнопка CTA, активный сегмент: градиент `#6d93b9 → #3d5870 → #2c4153 → #3d5870 → #6a8db2`, рамка `rgba(175,210,245,.45–.55)`, стрелка `#83bdfb`.
- Иконка в круге (`.icon-disc`): `radial-gradient(circle, #0e1c28 50%, #25394b 100%)` или `#102231 → #0a1923`.
- Плашки-чипы (`.ex__tag`, `.hero__muscle`): `linear-gradient(180deg, rgba(22,34,46,.92), rgba(8,15,23,.92))`, рамка `rgba(140,180,225,.16)`.
- Разделители строк: `1px solid rgba(150,190,255,.08)`.
- Падение показателя — не красный: `--accent-soft` с `opacity: .75`, знак «−».
- Видео Vital — белая/серая «студия» внутри тёмного UI, без заливок и размытия.

## Шрифт

`--font: -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'SF Pro Display', 'Inter Variable', system-ui, sans-serif` (SF Pro, на Android — Inter).
`1rem` = 16px при ширине 390px, весь макет масштабируется от ширины (`html { font-size: calc(min(100vw,480px) * 16/390) }`).

| Роль | Размер | Насыщенность |
|---|---|---|
| Заголовок экрана (Прогресс) | 1.375rem / 1.75rem | 700 |
| Заголовок экрана (Главная, Упражнения) | 1rem / 1.375rem | 600, letter-spacing −0.01em |
| Заголовок карточки | 0.9375rem / 1.1875rem | 600 |
| Строка карточки (Главная) | 0.77–0.81rem | 400 |
| Подзаголовок, мета | 0.59–0.69rem | 400, `--accent-soft` |
| Крупная цифра (проценты на персонаже) | 1.25rem | 700, `--accent`, tabular-nums |
| Кнопка CTA | 0.8063rem | 500 |
| Нижняя навигация | 0.5938rem | 400 |

Цифры — `font-variant-numeric: tabular-nums`.

## Компоненты (переиспользовать)

- **Карточка** — `.card` (рамка `--border`, радиус `--radius-card`, фон `--surface`, блик).
- **Главная кнопка** — `.cta` (высота 2.4312rem, pill, градиент Главной).
- **Иконка в круге** — `.icon-disc`.
- **Переключатель** — `.ex__seg` + `.ex__seg-btn` / `.is-on` (Зал/Дом/Без инвентаря, Неделя/Месяц).
- **Раскрывающаяся карточка** — как `.last` на Главной: `grid-template-rows: 0fr → 1fr`, 240–300ms `--ease-out`, шеврон поворачивается на 180°.
- **Нажатие** — класс `.tappable` (scale .97).
- **Отступы экрана** — `padding: 0 1.2875rem 0 1.4312rem`, зазор между карточками 0.4–0.5rem.
- **Иконки** — `src/components/Icons.tsx`: линия 1.8–2.2, round caps, `currentColor`. Иконки групп мышц — картинки `src/assets/groups/*.webp`.

## Персонаж

- По полу из анкеты: `src/data/character.ts` → `hero-male.webp` / `hero-female.webp` (кадр 853×799). На Главной и в «Прогрессе».
- Не перерисовывать, не перекрашивать, не менять позу, одежду, свет, кожу. Подписи и точки — поверх, линиями `--accent`.

## Навигация

Нижняя навигация, 4 пункта по порядку: **Главная / Упражнения / Прогресс / Профиль** (`src/components/BottomNav.tsx`).
